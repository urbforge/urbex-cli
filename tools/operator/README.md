# urbex-op: urbex in a container

`urbex` shells out to `terraform`, `ansible-playbook`, `sops`, `git` and
`ssh`. `urbex-op` runs it in a container that has all of them, at the
versions pinned in the repository's [`mise.toml`](../../mise.toml),
against a **workspace**: one directory holding everything a platform
needs on your side. Nothing gets installed on your machine but podman
(or docker).

## Quick start

```sh
tools/operator/urbex-op build                      # the image, from this checkout
tools/operator/urbex-op -w ~/urbex-work init       # the workspace: SSH key, age key
tools/operator/urbex-op -w ~/urbex-work set proxmoxToken   # asks for it; see docs/reference/credentials.md
tools/operator/urbex-op -w ~/urbex-work 'urbex bootstrap'
```

The first `bootstrap` writes `gitops/urbex.platform.yaml`: edit it (the
SSH public key printed by `init` goes in `proxmox.sshPublicKey`), then
run `bootstrap` again.

Put `urbex-op` on your `PATH`, and set `URBEX_WORKSPACE`, to type less:

```sh
ln -s "$PWD/tools/operator/urbex-op" ~/bin/urbex-op
export URBEX_WORKSPACE=~/urbex-work
urbex-op 'urbex status'
```

## The workspace

```
~/urbex-work/
├── home/                    $HOME in the container
│   ├── .urbex/credentials.yaml   generated by bootstrap (mode 0600)
│   ├── .ssh/urbex, urbex.pub     the key Ansible reaches the LXCs with
│   └── age.key                   encrypts every secret: back it up
├── gitops/                  the GitOps repo's working copy ($URBEX_GITOPS_REPO)
└── projects/                your projects' working copies (any layout works)
```

It is mounted at `/work` in the container: a project in
`~/urbex-work/projects/acme-app` is `/work/projects/acme-app` there.

**Keep it safe and backed up**: the credentials file and the age key are
secrets, and after `urbex teardown` the `gitops/` folder is the GitOps
repo's only copy.

## Credentials

`urbex` reads every credential from an environment variable first, then
from `home/.urbex/credentials.yaml` in the workspace. The two you
provide can go either way:

```sh
urbex-op set proxmoxToken        # asks without echoing; stored in the workspace, mode 0600
urbex-op set cloudflareToken
# or, for this shell only:
export URBEX_PROXMOX_TOKEN='urbex@pve!cli=...' URBEX_CLOUDFLARE_TOKEN='...'
```

`set` also takes the value on standard input (`printf %s "$TOKEN" |
urbex-op set proxmoxToken`), keeps the file's other entries, and works
for any key of the file (`ageKey` too - otherwise `home/age.key` is
used). Bootstrap keeps them when it adds its own, and `urbex teardown`
removes only the generated ones.

## Running commands

```sh
urbex-op 'urbex status'                                          # one command
urbex-op 'cd /work/projects/acme-app && urbex apply staging'      # in a project
urbex-op 'cd /work/projects/acme-app && urbex status staging'
urbex-op shell                                                    # an interactive shell
```

Each run starts a fresh container that:

- uses `/work/home` as `$HOME` (so `~/.urbex/credentials.yaml` is the
  workspace's) and `/work/gitops` as `URBEX_GITOPS_REPO`;
- exports `URBEX_AGE_KEY` from `home/age.key`, if that file exists and the variable isn't set;
- starts an SSH agent with `home/.ssh/urbex`;
- passes `URBEX_PROXMOX_TOKEN`, `URBEX_CLOUDFLARE_TOKEN` and
  `URBEX_AGE_KEY` from your environment, if set - they win over the
  credentials file;
- uses the host's network, so it reaches the Proxmox API and the LXCs on
  your LAN.

Files it creates belong to your user (podman maps it in).

## Where everything is

```sh
urbex-op 'urbex status'                                        # the platform's endpoints, and logins
urbex-op 'cd /work/projects/acme-app && urbex status staging'   # a project's, per service
```

See *Find every endpoint* in the cookbook
(`docs/cookbook.md` in urbforge/urbex).

## Variables

| Variable | Default | Meaning |
|---|---|---|
| `URBEX_WORKSPACE` | `~/urbex-workspace` | The workspace, if `-w` isn't given. |
| `URBEX_OPERATOR_IMAGE` | `urbex-operator` | The image `build` creates and runs use. |
| `URBEX_PROXMOX_TOKEN`, `URBEX_CLOUDFLARE_TOKEN`, `URBEX_AGE_KEY` | - | Passed to the container when set; otherwise the credentials file is used. |

Rebuild the image (`urbex-op build`, or `mise run operator-image`) after
updating this checkout: the image contains the `urbex` binary built from
it, and the tools at the versions `mise.toml` pins.
